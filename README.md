# moo

**Tokenizer generator** — define token patterns, generate efficient tokenizers. Input a spec, output a lexer.

## What This Gives You

- **Pattern definitions** — regex-based token specifications
- **Code generation** — output tokenizers in target languages
- **Priority rules** — resolve ambiguous patterns with explicit precedence
- **Minimal runtime** — generated tokenizers have zero dependencies

## How It Fits

Parser infrastructure for the SuperInstance ecosystem. Used by `flux-lang` and other DSLs in the constraint compilation pipeline.
